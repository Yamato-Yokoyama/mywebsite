## 1. Hiroki Naganuma — https://hiroki11x.github.io/

Yamato が「構成ではなく総合的な印象を参考にしたい」と挙げたサイト。

### 特徴分析

- **背景**: 白ベース
- **アクセント**: 濃い青 (`#003366` 系) を控えめに
- **フォント**: 読みやすいセリフ / サンセリフ組み合わせ
- **装飾**: ほぼゼロ、コンテンツで語る
- **写真**: 顔写真 1 枚 + ロゴ + プロジェクト画像のみ
- **構成**: 学術寄り (Publications, Awards, Talks が中心)
- **トーン**: PhD candidate らしい落ち着いた学術性

### mywebsite-v2 との対比

| 項目 | 長沼さん | Yamato v2 |
|---|---|---|
| 主対象 | アカデミック / 研究者 | 企業リクルーター + LinkedIn 流入 |
| 立ち位置 | PhD candidate | 学部生 (Applied AI Engineer 志望) |
| 中心コンテンツ | Publications | Projects + Community |
| トーン | 学術静寂 | モノトーンでミニマル、若さも残す |

### 学ぶ点

- 余白の使い方 (詰め込まない、呼吸を作る)
- 情報量を絞る勇気 (全て載せない)
- Typography に意味を持たせる階層設計
- 顔写真の入れ方 (小さめ、上部に控えめに)

### 真似しない点

- Publications セクション (Yamato は学部生で対象外)
- 学会 / 論文の羅列
- 学術寄りすぎるトーン (企業応募には少し硬すぎる可能性)

## デザイン方向性の最終決定 (2026-08-14 会話にて)

3 案を検討した結果:

- **A. 学術トーン (長沼さん寄り 100%)** → 不採用: 学部生には硬すぎる
- **B. 落ち着き + 若干のアクセント** → 不採用: 中途半端になるリスク
- **C. モノトーン + タイポで魅せる** → **採用**

C を選んだ理由:
1. 「言語 (タイポ) を扱う人」というメタメッセージが視覚で伝わる
2. 他の学生ポートフォリオが色を多用する中で逆張りとして目立つ
3. 色センスに頼らないので、AI 実装との相性が良い

C + UX 強化で:
- Bootstrap でスティッキーナビ・スムーススクロール・ホバー効果
- モバイル対応
- アクティブ状態のハイライトが「色を使う唯一の場所」
